# 洛书匣探针（tavernlib-probe）

一个**只读**的最小验证扩展：用来确认《酒馆》(TauriTavern) 手机版能不能装第三方扩展、扩展里能不能直接读到手机本机的角色卡数据。

不写入、不修改、不上传任何数据，全部结果只显示在手机上。

---

## 装好之后怎么判断

打开酒馆 → 首页右下角会出现一个蓝色按钮「**探针结果**」。

| 你看到的情况 | 说明 | 下一步 |
|---|---|---|
| 完全没有蓝色按钮 | 扩展没被加载运行 —— 这个版本的酒馆禁止第三方扩展 | iOS 走不通，需要换版本（见下方说明） |
| 有按钮，点开后【角色卡数量】> 0 | **成功**。扩展能跑，也能读到本机卡 | 洛书匣按扩展方案做 |
| 有按钮，但【角色卡读取】是失败 | 扩展能跑，但接口被拦或权限不足 | 把截图发我，我改接口调用方式 |
| 有按钮，【角色卡数量】= 0 | 接口通了，只是酒馆里没卡 | 导入一张卡再复测 |

点开面板后有「复制结果」按钮，可以直接把整份结果复制发我。

---

## 关键结论：iOS 有版本门槛

查阅 TauriTavern 官方源码文档（`docs/CurrentState/iOSPolicy.md`）确认：

- **公开 TestFlight 外测版**（profile = `ios_external_beta`）默认**关闭**了第三方扩展：
  - `extensions.third_party_management` = 关闭（不能安装/更新/删除扩展）
  - `extensions.third_party_execution` = 关闭（装了也不执行）
  - 只有 5 个官方扩展白名单可以跑
- **内测版 / 自签 IPA（full 版）**：不限制，可以装可以跑。

所以：如果你手机上装的是公开测试版，按钮不会出现，这不是探针的问题。

## 安装方式

酒馆只接受 **Git 地址** 安装扩展（手机上没有"从文件夹/ZIP 安装"的入口）。

在酒馆里：扩展 → 安装扩展 → 填仓库地址 → 确认。
